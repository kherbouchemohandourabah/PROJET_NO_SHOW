# Description du projet (Portfolio)

Ce projet présente le déploiement complet d’une solution IA permettant de prédire les absences (“No-Show”) à un rendez-vous médical.

Points clés :
- Préparation des données et feature engineering
- Gestion du déséquilibre des classes avec SMOTE
- Modélisation avec XGBoost
- Déploiement d’une API REST avec FastAPI
- Conteneurisation avec Docker
- Gestion professionnelle du dépôt GitHub (commits, issues, pull requests)
